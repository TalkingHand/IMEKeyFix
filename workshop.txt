version=1
title=IME Key Fix
description=[h1]IME Key Fix[/h1]
description=Typing with a Korean, Chinese or Japanese IME? When the IME is in native mode (e.g. Hangul), Project Zomboid's hotkeys do nothing, because Windows gives every key press to the IME instead of the game.
description=
description=This mod turns the IME off for the game window while you play, so hotkeys always work, and turns it back on while you type in a text box: crafting and building search, chat, sign text. The IME keeps its mode, so a search box takes Hangul (or Pinyin, Kana) right away.
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*]Windows
description=[*][b]ZombieBuddy[/b] (Java mod loader), enabled in the mod list
description=[*]Steam launch option [b]-agentlib:zbNative --[/b] (Project Zomboid → Properties → Launch options). Without it the mod does not load.
description=[/list]
description=On the first start ZombieBuddy asks once to approve IMEKeyFix.jar.
description=
description=[h2]Tested[/h2]
description=Checked with the Windows Korean IME and the Microsoft Japanese IME. Chinese IMEs work the same way in Windows and should be fine, but were not tried; feedback welcome.
description=The game cannot show the word you are composing inside its text boxes, so text appears when you commit it (vanilla behaviour).
description=
description=[h2]Compatibility[/h2]
description=Client-side only. Only the game window is affected; other programs keep their IME. Changes no save data, safe to add or remove at any time.
description=
description=[h2]한국어[/h2]
description=한글 입력 상태에서 좀보이드 단축키가 안 먹히는 문제를 고칩니다. 게임 중에는 게임 창의 IME를 꺼서 한/영 상태와 상관없이 단축키가 먹고, 제작·건설 검색창, 채팅, 표지판 같은 입력칸을 누르면 IME를 다시 켭니다. 한/영 상태는 그대로 유지되어 한글로 두었다면 검색창에 바로 한글이 입력됩니다.
description=한국어·일본어 IME로 확인했습니다. 필요한 것: Windows, ZombieBuddy 모드, 스팀 실행 옵션 [b]-agentlib:zbNative --[/b] (속성 → 실행 옵션). 클라이언트 전용이며 세이브를 바꾸지 않습니다.
